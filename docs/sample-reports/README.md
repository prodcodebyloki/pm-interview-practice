# Sample reports

Screenshots of real end-of-session reports, shown in the main README.

## Image guidelines
| | Recommended |
|---|---|
| Format | PNG (or WebP) |
| Width | **1600 px**, which is sharp on retina screens. The main README displays it at 800 px. |
| Height | Any. For a full-page report, crop to about 1600 × 2400 px, or split it into two images. |
| Hero / overview shot | **1600 × 900 px** (16:9): the top of the report (overall rating + scores chart) |
| File size | Under **1 MB** each (compress with TinyPNG or `pngquant`) |
| Count | 2-3 images is plenty |

## Naming
- `report-overview.png`: the top section (rating, work summary, scores by dimension)
- `report-plan.png`: strengths/weaknesses, improvement plan, time per stage
- `report-trend.png`: the trend chart (after a few sessions)

You can also commit an anonymized `.html` report here (for example `sample-report.html`) so people can open the interactive version.

> Before committing, remove anything personal from the quotes (your name, employer, real numbers).
